# AR-Shooting

Meta Quest 向けの AR ターゲットシューティングゲームです。パススルーで現実の空間を映しながら、周囲に現れて動き回るターゲットを両手のコントローラーで撃ち落とし、60 秒間のスコアを競います。

## 特徴

- **現実の空間がそのままステージに:** パススルーを使い、プレイヤーがいる部屋の中にターゲットが現れます。
- **両手で撃てる:** 左右のコントローラーにそれぞれ発射位置があり、トリガーで別々に撃てます。
- **撃つ動作でゲームを開始:** スタートボタンの代わりに、点滅するターゲットを撃って始めます。メニュー操作を挟まず、そのままプレイに入れます。
- **毎回変わるプレイ展開:** ターゲットの種類、出現位置、動き方はランダムに決まります。

## ゲームの内容

1. 起動時に表示される、色が点滅するスタートターゲットを撃ちます。
2. 制限時間の 60 秒以内に、できるだけ多くのターゲットを撃ち落とします。
3. 時間切れになるとスコアが表示され、15 秒後にスタート画面へ戻ります。

左右の人差し指トリガーで、それぞれの手から弾を発射します。

| ターゲット | HP | 得点 | 出現率 |
| --- | --- | --- | --- |
| 黄 | 1 | 1 | 60% |
| 赤 | 3 | 3 | 20% |
| 緑 | 1 | 0 | 20% |

## 実装のポイント

### 継承によるターゲットの共通化

HP の管理、命中時の効果音、撃破時の点滅演出は基底クラスの `Target` にまとめました。`YellowTarget`、`RedTarget`、`GreenTarget` は HP と得点を設定するだけで、少ないコードで種類を増やせます。

### 移動処理のコンポーネント分離

動きは `Target` から独立した `TargetMovement` が担当します。出現位置を中心に、水平、垂直、円、リサジュー曲線のいずれかのパターンで動きます。使うパターンはプレハブごとのリストから抽選するので、コードを変えずに組み合わせを調整できます。

### プレイヤーを基準にした出現制御

`TargetSpawner` は、プレイヤーの正面から左右 80 度以内、距離 1.5〜3 m の円弧上にターゲットを配置します。高さはプレイヤーに合わせています。2 秒ごとに重み付き抽選で種類を選び、同時に存在できる数は 5 体までに制限しています。これらの値はインスペクターから変更でき、ゲームバランスの調整がしやすい構成です。

### ゲーム進行の一元管理

スコア、タイマー、UI、BGM、効果音は、シングルトンの `GameManager` に集約しました。ほかのスクリプトは `GameManager` を通して得点の加算や効果音の再生を行います。

## プロジェクト構成

```text
Assets/
├── Audio/      BGM・効果音
├── Prefabs/    弾とターゲットのプレハブ
├── Scenes/     StartScene、GameScene など
└── Scripts/    ゲームのスクリプト
```

| スクリプト | 役割 |
| --- | --- |
| `GameManager` | スコア、タイマー、UI、BGM、効果音の管理 |
| `BulletShooter` | トリガー入力の検出と弾の発射 |
| `Bullet` | 命中時の処理と弾の破棄 |
| `Target` | ターゲットの基底クラス |
| `YellowTarget` / `RedTarget` / `GreenTarget` | ターゲットごとの HP と得点の設定 |
| `TargetMovement` | ターゲットの移動パターン |
| `TargetSpawner` | ターゲットの抽選と出現 |
| `StartTarget` | スタートターゲットの点滅とゲーム開始 |
| `DebugUI` | ヘッドセット内へのメッセージ表示 |

## 実行方法

Android Build Support を含む Unity 6000.3.14f1 と、開発者モードを有効にした Meta Quest が必要です。

1. リポジトリをクローンし、Unity Hub からプロジェクトを開きます。必要なパッケージは自動で取得されます。
2. **File > Build Profiles** を開き、Android プロファイルに切り替えます。
3. Quest を PC に接続し、**Build And Run** を実行します。

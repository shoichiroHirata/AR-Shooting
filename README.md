# AR-Shooting

Meta Quest 向けの AR ターゲットシューティングゲームです。パススルーで現実の空間を映しながら、周囲に現れて動き回るターゲットを、両手のコントローラーで撃ち落として 60 秒間のスコアを競います。

## 遊び方

1. アプリを起動すると、色が点滅するスタートターゲットが表示されます。
2. スタートターゲットを撃つとゲームが始まります。
3. 制限時間の 60 秒以内に、できるだけ多くのターゲットを撃ち落とします。
4. 時間切れになるとリザルトが表示され、15 秒後にスタート画面へ戻ります。

### 操作方法

| 入力 | 動作 |
| --- | --- |
| 左コントローラーの人差し指トリガー | 左手から発射 |
| 右コントローラーの人差し指トリガー | 右手から発射 |

### ターゲットの種類

| 色 | HP | 得点 | 出現率 |
| --- | --- | --- | --- |
| 黄 | 1 | 1 | 60% |
| 赤 | 3 | 3 | 20% |
| 緑 | 1 | 0 | 20% |

ターゲットはプレイヤーの前方に 2 秒ごとに出現し、同時に存在できるのは最大 5 体です。出現後は水平・垂直・円・リサジュー曲線のいずれかのパターンで動きます。

## 必要な環境

- Unity 6000.3.14f1(Android Build Support を含む)
- 開発者モードを有効にした Meta Quest 端末
- USB ケーブルなど、PC と端末を接続する手段

主なパッケージは次のとおりです。Unity でプロジェクトを開くと自動的に取得されます。

- Universal Render Pipeline 17.3
- Meta XR Core SDK / Interaction SDK OVR 201.0.0
- OpenXR Plugin 1.16.1

## セットアップ

```sh
git clone https://github.com/shoichiroHirata/AR-Shooting.git
```

Unity Hub からクローンしたフォルダーを Unity 6000.3.14f1 で開きます。`Library/` はリポジトリに含まれていないため、初回はインポートに時間がかかります。

## ビルドと実行

コマンドラインのビルドスクリプトはないため、Unity エディターからビルドします。

1. **File > Build Profiles** を開き、Android プロファイルに切り替えます。
2. Quest を PC に接続します。
3. **Build And Run** を実行すると、APK がビルドされて端末にインストールされます。

ビルドに含まれるシーンは `StartScene`、`GameScene` の順です。`SampleScene` は無効になっています。

## プロジェクト構成

```text
Assets/
├── Audio/      BGM・効果音
├── Prefabs/    弾とターゲットのプレハブ
├── Scenes/     StartScene、GameScene など
└── Scripts/    ゲームのスクリプト
```

| スクリプト | 役割 |
| --- | --- |
| `GameManager` | スコア、タイマー、UI、BGM、効果音の管理 |
| `BulletShooter` | トリガー入力の検出と弾の発射 |
| `Bullet` | 命中時の処理と弾の破棄 |
| `Target` | ターゲットの基底クラス(HP、得点、撃破演出) |
| `YellowTarget` / `RedTarget` / `GreenTarget` | ターゲットごとの HP と得点の設定 |
| `TargetMovement` | ターゲットの移動パターン |
| `TargetSpawner` | ターゲットの抽選と出現 |
| `StartTarget` | スタートターゲットの点滅とゲーム開始 |
| `DebugUI` | ヘッドセット内へのメッセージ表示 |

## 調整できる値

制限時間は `GameManager`、出現率・出現数・出現範囲は `TargetSpawner`、弾速は `BulletShooter` のインスペクターで、シーンごとに変更できます。ターゲットの HP と得点は各サブクラスの `Start()` でコードから設定されるため、インスペクターの値は使われません。

## 開発時の注意

- 既存の `.cs` ファイルは Shift-JIS(CP932)、改行コードは CRLF です。別の文字コードで保存すると、日本語のコメントが文字化けします。
- ゲームのロジックは `Target` と `Bullet` のタグに依存しています。
- シリアライズフィールドを追加または変更したら、Unity エディターでシーンやプレハブの参照を設定し直してください。
